山と森に囲まれたキャンパスで、世界中から集う仲間と過ごす5年間。 そこで育つのは、テクノロジーと文化を翻訳できる人材(ダミー)。

Five Spices of Learning

5つのスパイスのように、学びを彩る特徴(ダミー)。

テクノロジー

プログラミング、AI、ロボティクスを、辛味のように効かせる。

デザイン

寺院の細やかな彫刻のような、ものづくりの美しさを学ぶ。

起業家精神

踊るように軽やかに、価値を社会へ届けるマインドセット。

教養

古代の知恵書のように、深く広く世界を読み解く力を養う。

Curriculum Journey

5年間のカリキュラムを、ガンジス川の流れのようにたどる(ダミー)。

  1. 1年生 / प्रथम

    基礎の種を蒔く

    プログラミング、デザイン、教養の基礎をまるごと体験。

  2. 2年生 / द्वितीय

    スパイスを選ぶ

    興味分野を選び、プロジェクトに取り組む。

  3. 3年生 / तृतीय

    混ぜ合わせる

    チーム開発と外部連携で、現場の熱を浴びる。

  4. 4年生 / चतुर्थ

    煮込む

    インターンシップと専門深化で、自分の味を作る。

  5. 5年生 / पंचम

    皿に盛る

    卒業制作・起業準備など、世界に届く一皿に仕上げる。
